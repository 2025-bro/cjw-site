# 学习计划 v2：CF 1200 → 1800（2026-10-18 ~ 12-31）

> **v1 的偏差**：v1 把你当成"模板从零学"，排了大量 贪心/排序/前缀和/二分查找/并查集/最短路 的基础周——这些你**已经有模板了**。
> **v2 的假设**：模板是工具，主线是 **「应用 + 补缺口 + 独立完成率」**。

## 六、比赛策略（没变，但更重要了）

1. 前 5 分钟扫 A–C，按难度而非字母顺序写；
2. 思考上限：A 5′ / B 12′ / C 20′ / D 30′，超时换题；
3. 提交前 30 秒自查：多测 / n=1 / 全相同 / `long long` / 数组大小 / 0-1 下标；
4. WA 先确认**有没有读错题**；
5. 掉 50+ 分当天停打；
6. **每场结束 30 分钟内补 A/B，当天补 C，次日补 D**。
